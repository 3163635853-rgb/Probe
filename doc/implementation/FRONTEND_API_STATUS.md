# 前端接口接入状态

> 最后更新：2026-07-16。以当前 `web/` 和 `mobile/` 实现为准。

## Web 已接入

- 认证：注册、登录、微信登录、当前用户、资料更新、SSE ticket
- 配置：行业、岗位、模式、难度
- 面试：开始、流式连接、回答、跳过、结束、报告、历史、活跃会话、统计
- 配额：当前配额与无限套餐判断
- 支付：套餐、微信支付 API v3 JSAPI/H5 创建订单、订单列表
- 订阅：当前订阅、自动续费开关
- 邀请：邀请码、兑换、邀请记录
- 通知：列表、未读数、单条已读、全部已读
- 优惠券：列表、兑换、支付时使用 coupon_id
- 成就：成就列表
- 语音：浏览器录音转写、AI TTS 播放
- 文件：头像上传和资料更新
- 分享：服务端生成图片、记录分享渠道；生成失败时保留 html2canvas 降级
- 反馈：面试反馈

## Mobile 已接入

- 邮箱认证与安全 Token 存储
- 配置、面试、SSE、历史、报告、统计、配额
- 语音录制转写和 AI 音频播放
- 会员状态、H5 微信支付、优惠券兑换
- 邀请、通知、成就、反馈、推送 Token、App 版本
- 服务端分享图与系统分享面板
- 成长中心：等级、XP、连续训练、周目标、七日活动、能力聚焦和每日任务

## 后端专用或无需前端直接调用

- `POST /payment/webhook`：微信支付服务器回调
- `GET /share/callback/{id}`：公开分享点击回调
- `GET /share/image/{uuid}.png`：公开图片资源
- `GET /health`：部署健康检查

## 质量门禁

- Web：`npm run lint && npm run build`
- Mobile：`npm run check`
- Backend：`uv run pytest -q`
- CI 会同时执行数据库迁移和两个 Compose 文件的配置校验。
