## Phase 1 完成标准

```
✅ 外网 HTTPS 可访问
✅ 微信登录 (开发模式 mock 可用)
✅ 选择行业/岗位/模式/难度 → 开始面试
✅ Agent 流式追问 8-12 题 (有追问深度)
✅ 面试结束 → 完整报告 (雷达图 + 逐题点评)
✅ 历史面试可查看
✅ 免费 3 次/月配额控制
✅ 手机浏览器可用
✅ 基本稳定 (SSE 断线恢复, LLM 超时有兜底)
```
