## 一、项目定位

一个 **AI 智能体驱动的多模态面试训练平台**。不是简单的 Prompt 调 API——是完整的智能体架构：面试官 Agent 自主规划面试流程、调度记忆系统、检索知识库、调用评估工具，模拟真实面试官的思考过程。

**一句话**：造一个会思考、有记忆、懂面试的 AI 面试官。

## 二、智能体架构（核心）

### 2.1 Agent 循环 (ReAct + 记忆)

```
用户说"开始面试"
  → Agent 初始化
  → [循环开始]
      1. 感知: 读用户回答 + 当前面试进度
      2. 记忆: 检索短期记忆(本轮对话) + 长期记忆(用户历史短板)
      3. 检索: 向量搜索知识库 → 找到相关面试题/评分标准
      4. 推理: LLM 决策 → 追问？换题？给提示？结束？
      5. 行动: 生成下一题 / 追问 / 评分 / 结束
      6. 存储: 写入记忆(Mem0/Redis + 向量库)
  → [循环结束]
  → 生成报告
```

### 2.3 Agent 状态机

```
                 ┌─────────────┐
                 │   IDLE      │ ← 等待用户开始
                 └──────┬──────┘
                        │ 用户点击"开始面试"
                 ┌──────▼──────┐
                 │ PLANNING    │ ← 规划器制定面试大纲
                 └──────┬──────┘
                        │
                 ┌──────▼──────┐
            ┌───►│ QUESTIONING │ ← 出题
            │    └──────┬──────┘
            │           │ 用户回答
            │    ┌──────▼──────┐
            │    │ EVALUATING  │ ← 评估器打分
            │    └──────┬──────┘
            │           │
            │    ┌──────▼──────┐
            ├────┤ DECIDING    │ ← 追问？换题？结束？
            │    └──────┬──────┘
            │           │ 达到结束条件
            │    ┌──────▼──────┐
            └────┤ PROBING     │ ← 追问器深挖（可选）
                 └──────┬──────┘
                        │ 所有问题完成
                 ┌──────▼──────┐
                 │ REPORTING   │ ← 生成面试报告
                 └──────┬──────┘
                        │
                 ┌──────▼──────┐
                 │   DONE      │
                 └─────────────┘
```

**结束条件**: 预设题数完成(8-12) / 用户主动结束 / 超时45min / Agent判断已充分评估

## 五、记忆系统

### 三层架构

| 层级 | 存储 | 生命周期 | 用途 |
|------|------|---------|------|
| **工作记忆** | Redis (TTL 2h) | 单次面试 | 上下文、Agent 状态、追问策略 |
| **短期记忆** | Milvus | 30 天 | 语义召回、避免重复 |
| **长期记忆** | Mem0 + MySQL | 永久 | 用户画像、个性化面试 |

### 检索流程

```
Agent 决策前:
  ├── Redis → 最近 3 轮对话
  ├── Milvus → 语义搜历史相似回答
  └── MySQL/Mem0 → 用户画像 → 调整难度和方向
```

## 七、技术栈

| 层 | 选型 | 理由 |
|---|---|---|
| 后端 | Python 3.12 + FastAPI + uv | LLM 生态、异步、SSE 原生 |
| Agent | 自研 Loop | 面试逻辑固定，不需要通用框架复杂性 |
| LLM | MiMo (小米) API | OpenAI 兼容、中文好、token-plan 低成本 |
| 向量库 | FAISS (Phase 1) → Milvus (Phase 2+) | 零运维起步 |
| Embedding | BGE-M3 本地 | 中文最强开源，1024d |
| 关系库 | MySQL 8.0 | 结构化数据 |
| 缓存 | Redis 7 | 工作记忆、限流 |
| 记忆 | Mem0 (Phase 3) | 长期画像自动提取 |
| Web | Next.js 14 + Tailwind | SSR、快速开发 |
| App | React Native (Phase 2) | 跨端 |
| 小程序 | 微信原生 (Phase 3) | 国内入口 |
| 语音 | Whisper + Edge TTS | 免费本地 |
| 网关 | Caddy 2 | 自动 HTTPS |
| 部署 | DO + Docker Compose | 简单低成本 |
| ORM | SQLAlchemy 2.0 async | 类型安全 |

## 八、关键决策

| 决策 | 选择 | 否决 | 理由 |
|------|------|------|------|
| Agent 框架 | 自研 | LangChain | 面试逻辑固定，不需要通用框架 |
| 实时通信 | SSE | WebSocket | 单向推送为主，SSE 更简单 |
| 向量库 | Milvus | Qdrant/Pinecone | 开源、混合检索、自部署 |
| 部署 | Docker Compose | K8s | 早期单机够用 |
| LLM | DeepSeek | GPT-4 | 成本低 10x，中文够用 |

## 十、数据流：一次完整面试

```
[选岗位+粘JD] → POST /start → 创建 session + Redis 状态
       ↓
[SSE 连接] ← Planner 生成大纲 → 推首题
       ↓
[用户回答] → POST /answer → Evaluator 评分 → Memory 写入
       ↓                       ↓
                          Prober 追问? → 是 → SSE 推追问
                               ↓
                          Planner 下一题 → SSE 推题
       ↓
[循环 8-12 轮]
       ↓
Reporter 生成报告 → 写 MySQL + Milvus → SSE event:report → 前端展示
```
